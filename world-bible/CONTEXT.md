# World Bible Contents

Routing guide for agents entering the world bible. Each bible file covers a specific layer of the world. Load only what the current stage needs.

## File Guide

| File | Contains | Load When |
|------|----------|-----------|
| world-overview.md | World name, genre, premise, era, tone | Starting any creative task -- always the first file loaded |
| factions.md | Major factions, allegiances, allegiances, conflicts | Writing faction-related content or political context |
| characters.md | Protagonist and antagonist archetypes, key figures, personality | Writing or designing characters |
| character-appearance.md | Physical descriptions, facial features, hair, clothing, gear, weapons | Any task requiring visual accuracy -- essential for character artist |
| world-rules.md | Technology level, physics, society structure | Any task requiring world consistency checks |
| timeline.md | Key historical events, current moment in the story | Writing narrative or pitch context requiring historical grounding |

## Loading Rule

Never load all bible files at once. The stage CONTEXT.md Inputs table specifies which files and which sections to load. Loading more than needed dilutes model attention.
